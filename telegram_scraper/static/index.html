Where do I get the API ID and hash?
  1. Open Telegram’s API development tools ↗ and sign in with your phone number.
  2. Create an application if Telegram asks, then copy its api_id and api_hash into the fields below.
  3. Save settings, then connect your Telegram account below using your phone, login code and, if enabled, two-step password.

These are account API details. A BotFather bot token cannot be used here. Login codes and passwords are not saved in settings.
